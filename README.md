# RTES 2026

Εργασία για το μάθημα «Ενσωματωμένα Συστήματα Πραγματικού Χρόνου».

Το project υλοποιήθηκε σε C και εκτελέστηκε σε Raspberry Pi με αρχιτεκτονική Producer-Consumer, κυκλικό buffer και ανεξάρτητο Monitor thread.

## Περιεχόμενα

- `src/` : πηγαίος κώδικας C
- `include/` : αρχεία header
- `Makefile` : αρχείο μεταγλώττισης
- `metrics_log.txt` : δεδομένα από τη συνεχή 24ωρη εκτέλεση
- `plot_results.py` : πρόγραμμα επεξεργασίας των δεδομένων
- `plots/` : διαγράμματα Jitter, Buffer/Load και CPU

## Αποτελέσματα 24ωρης εκτέλεσης

- 86400 δείγματα
- 0 ελλείποντα δείγματα
- 0 μεγάλα κενά χρονισμού
- 0 διπλότυπα δείγματα

Η εκτέλεση πραγματοποιήθηκε στο φυσικό hardware του Raspberry Pi.
